**Oltepesi Activities Management System**

**Description**

This is a Django-based web application for managing harvester activities, groups, and team leaders. It includes admin features such as activity tracking, filtering, and exporting data to CSV.

**Features**

1. Manage groups and team leaders

2. Track harvester activities

3. Django admin dashboard

4. Filtering for records

5. Export selected activities to CSV

**Project Status**

This project is currently under active development. Some features may change as improvements and new requirements are added over time.
